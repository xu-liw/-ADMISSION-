# ADMISSION - 手機直式水平無縫長圖作品集

這是一個專為手機直式瀏覽打造的純靜態作品集網站，支援零間距無縫水平長圖、無限循環滑動、原生系統分享與社群導流。

## 📦 部署至 GitHub Pages（純靜態）

本專案為 100% 純靜態網站，**不需要任何後端或 API Key**。

### 檔案結構
將以下檔案放置於您的 GitHub Repository 根目錄：
- `index.html`（可直接使用專案內的 `public/github-pages-index.html`）
- `slide-1.png`
- `slide-2.png`
- `slide-3.png`
- `slide-4.png`
- `slide-5.png`
- `slide-6.png`
- `slide-7.png`

### 3 步驟啟用 GitHub Pages：
1. 進入 GitHub Repository 的 **Settings**。
2. 點選左側選單的 **Pages**。
3. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 與 `/ (root)`，點擊 **Save** 即可發布上線！

## ✨ 功能特色
- **純直式手機鎖定**：非手機裝置或手機橫躺時，畫面呈現 `slide-7.png` 背景與白色提示字 `Please use phones vertically.`。
- **無縫無限循環（3-Panel Ring Engine）**：滑到最後一頁後平滑銜接回第 1 頁，永不卡頓或丟圖。
- **極簡手勢提示**：首頁提示顯示 2 秒後平滑淡出，箭頭精準正中。
- **分享與社群**：原生系統分享（標題為 ADMISSION）、個人 Instagram、個人 YouTube 頻道。
